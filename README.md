## Installation

### Option 1: Install from GitHub (Recommended)

Clone the repository:

```bash
git clone https://github.com/USERNAME/codex-skills.git
```

Install the skill:

```bash
mkdir -p ~/.codex/skills
cp -R codex-skills/code-review-security ~/.codex/skills/
```

### Option 2: Install from ZIP

Download `code-review-security.zip` and run:

```bash
mkdir -p ~/.codex/skills
unzip ~/Downloads/code-review-security.zip -d ~/.codex/skills
```

## Usage

Restart Codex if necessary, then invoke:

```text
$code-review-security
```
